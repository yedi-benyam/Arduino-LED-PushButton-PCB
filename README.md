# Arduino LED & Push Button PCB

## Overview
This project is a simple Arduino Nano PCB designed in KiCad. It demonstrates basic PCB design practices, including schematic capture, component placement, routing, and design rule checking.

## Components
- Arduino Nano
- Push Button
- LED
- 220 Ω Resistor
- 10 kΩ Resistor

## Features
- Push button input
- LED output
- Compact single-layer PCB
- Designed using KiCad 10
